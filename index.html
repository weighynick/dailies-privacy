Privacy Policy — AI Dailies Uploader

Last updated: 27 July 2026

AI Dailies Uploader (the "API Client") is a personal command-line script, operated by PEZET Nicolas (the "Operator"), that uploads videos the Operator has produced to YouTube channels the Operator owns.

The API Client is not a product, not a service, and is not distributed. It runs locally on the Operator's own computer and has exactly one user: the Operator. It has no sign-up, no hosted interface, and no way for any other person to use it or to submit data to it. Consequently, this policy describes the handling of the Operator's own data only.

YouTube API Services

The API Client uses YouTube API Services. By using it, the Operator is bound by the YouTube Terms of Service. Google's handling of data is described in the Google Privacy Policy.

What the API Client accesses

The API Client requests a single OAuth scope, https://www.googleapis.com/auth/youtube.upload, and calls exactly two endpoints:

  • videos.insert — uploads a video file rendered locally by the Operator, together with its title, description and tags. Twice per day, once per channel.
  • channels.list with mine=true — reads only the ID and title of the authorized channel. Because both of the Operator's channels sit under one Google Account, the API Client verifies before every upload that the authorized channel is the intended one, and aborts if it is not.

The API Client does not read, display, download, store or process YouTube content, channels, playlists, comments, or analytics belonging to anyone else. It does not use YouTube data to build or enrich any profile, dataset or model.

What is stored, and where

The following is written to the Operator's local filesystem and nowhere else:

  • An OAuth refresh token and access token per channel, used to authenticate subsequent uploads without repeating the consent flow.
  • The channel ID and channel title returned by channels.list, used solely for the safety check described above.
  • A local log of which video files have already been uploaded, so that a repeated run does not publish the same video twice.

No server, database or third-party service is involved. Nothing is transmitted anywhere except directly to Google's API endpoints over HTTPS in order to perform the upload.

Sharing and sale of data

No data of any kind is shared with, sold to, or disclosed to any third party. There are no analytics, no advertising, no tracking, and no third-party SDKs.

Retention and deletion

Stored tokens remain valid until the Operator revokes them or deletes the local token files. Deleting those files removes all authorization data held by the API Client. Uploaded videos remain on YouTube under the Operator's control and can be deleted from YouTube at any time.

Revoking access

Authorization granted to the API Client can be revoked at any time at https://myaccount.google.com/permissions. Revocation immediately and permanently prevents any further API access.

Children

The API Client has no users other than the Operator and is not directed at children.
